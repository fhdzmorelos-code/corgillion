# Corgillion

Juego de trivia en español: cada consigna pide nombrar algo, y cuanto más rara sea tu respuesta, más hondo cava tu corgi. Hecho para jugar en computadora.

- **Clásica** y **Pokémon**, cada una con cuatro modos: Diario, Libre, Sin final y Contrarreloj.
- Cada día se añaden 20 consignas nuevas; el modo Diario es el mismo para todos y solo se puede jugar una vez al día.
- Tabla de posiciones entre amigos (con apodo y PIN).

Es una página estática: abre `index.html` o publícala con GitHub Pages. La base de datos de la tabla de posiciones está en `supabase/`.
